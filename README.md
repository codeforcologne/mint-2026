# mint-2026
Alle diese 3D-Modelle wurden im Rahmen des [Kölner MINT Festivals 2026](https://mint-festival.de/) erstellt, und stehen unter der freien [Creative Commons Zero (CC0) Lizenz](https://creativecommons.org/publicdomain/zero/1.0/). 

**Webseite: https://codeforcologne.github.io/mint-2026/**

3D-Modelle für Webanwendungen sollten grundsätzlich optimiert werden, um Resourcen zu sparen. Hier wurde die freie Software [glTF Transform](https://gltf-transform.dev/) dafür verwendet. Optimierte Modelle sind mit einem "_opt" Postfix gekennzeichnet. Die Qualitätsverluste sind bei den üblicherweise verwendeten Ausgabebildschirmen kaum zu erkennen.  

Die 3D-Modelle können online z.B. im [glTF Viewer](https://gltf-viewer.donmccurdy.com/) angeschaut werden.
